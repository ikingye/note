                                                政治哲学 #

                                                古典政治哲学 #

                                                （公元前 5C – 公元 5C）

                                                柏拉图 Plato #

                                                核心著作： 《理想国》《法律篇》 关键词： 正义、哲人王、理想国、等级制、灵魂三分

                                                要点：

                                                • 正义是每个部分做好自己的事。
                                                • 哲人王统治才能保证国家的正义。
                                                • 通过灵魂结构 → 国家结构的类比建立政治伦理模型。

                                                亚里士多德 Aristotle #

                                                核心著作： 《政治学》 关键词： 政体分类、中庸、中产阶级、城邦、德性政治

                                                要点：

                                                • 人是“政治的动物”（zoon politikon）。
                                                • 最稳定的政体是“混合政体 + 均衡的中产阶级”。
                                                • 目的论：政治是实现“良好生活”的工具。

                                                西塞罗 Cicero #

                                                核心著作： 《论共和国》《论法律》 关键词： 自然法、共和政、混合宪制

                                                要点：

                                                • 公民共同体（res publica）的基础是正义。
                                                • 自然法高于国家法。

                                                中世纪政治哲学 #

                                                奥古斯丁 Augustine #

                                                著作： 《上帝之城》 关键词： 尘世之城、上帝之城、救赎、基督教政治秩序

                                                要点：

                                                • 世俗政治无法实现真正的正义，只能维持秩序。
                                                • 真正的正义属于“上帝之城”。

                                                阿奎那 Thomas Aquinas #

                                                著作： 《神学大全》《政治论》 关键词： 自然法、神法、人法、君主制

                                                要点：

                                                • 法律是“理性为公共利益所做的安排”。
                                                • 人法必须符合自然法。
                                                • 反对暴政，可在一定条件下反抗暴君。

                                                近代政治哲学（现代国家的理论基础） #

                                                马基雅维利 Machiavelli #

                                                著作： 《君主论》《李维史论》 关键词： 现实主义、权力、共和主义、德行（virtù）、机遇（fortuna）

                                                要点：

                                                • 政治应基于现实，而非道德理想。
                                                • 德行是一种“有效行动的能力”。

                                                霍布斯 Hobbes #

                                                著作： 《利维坦》 关键词： 自然状态、战争状态、主权、社会契约

                                                要点：

                                                • 自然状态是“人人对人人的战争”。
                                                • 为逃离恐惧，人们将权力让渡给主权者。
                                                • 主权必须统一、绝对。

                                                洛克 Locke #

                                                著作： 《政府论两篇》 关键词： 自然权利、财产、人民主权、革命权

                                                要点：

                                                • 自然状态是和平的，但缺乏公正裁决。
                                                • 财产权是自然权利的延伸。
                                                • 若政府侵犯自然权利，人民有权革命。

                                                卢梭 Rousseau #

                                                著作： 《社会契约论》 关键词： 公意（General Will）、自由、公民身份、人民主权

                                                要点：

                                                • “人生而自由，却无往不在枷锁之中。”
                                                • 公意是以共同利益为导向的公共理性。
                                                • 真正自由来自共同立法。

                                                孟德斯鸠 Montesquieu #

                                                著作： 《论法的精神》 关键词： 三权分立、温和政府、政治气候

                                                要点：

                                                • 将立法/行政/司法分立是自由的保障。
                                                • 政治制度受“地理、气候、习俗”影响。

                                                托克维尔 Tocqueville #

                                                著作： 《论美国的民主》 关键词： 平等、民主社会、地方自治、过度民主

                                                要点：

                                                • 民主的力量来自“习俗 + 地方自治”。
                                                • 过度平等会带来“温和的专制”。

                                                当代政治哲学（20C–Now） #

                                                罗尔斯 John Rawls #

                                                著作： 《正义论》《政治自由主义》 关键词： 原初状态、无知之幕、差别原则、制度正义

                                                要点：

                                                • 正义是制度的“第一美德”。
                                                • 公平的原则来自无知之幕后达成的共识。

                                                诺齐克 Robert Nozick #

                                                著作： 《无政府、国家与乌托邦》 关键词： 最小国家、自我所有权、自由至上主义

                                                要点：

                                                • 反对罗尔斯的“再分配正义”。
                                                • 国家功能应极限于保护个体权利。

                                                阿伦特 Hannah Arendt #

                                                著作： 《人的境况》《极权主义的起源》 关键词： 公共领域、行动、自由、极权主义

                                                要点：

                                                • 真正的自由来自“公共空间中的行动”。
                                                • 极权主义是现代孤立与原子化的产物。

                                                福柯 Michel Foucault #

                                                著作： 《规训与惩罚》《性史》《生物政治课程》 关键词： 权力/知识、规训社会、生命政治、治理术

                                                要点：

                                                • 权力分散在社会网络，而非由主权者垄断。
                                                • 现代国家通过“规训 + 生物政治”组织人口。

                                                哈贝马斯 Jürgen Habermas #

                                                著作： 《交往行为理论》《事实与规范》 关键词： 公共领域、交往理性、商谈民主

                                                要点：

                                                • 理性不是工具性的，而是沟通性的。
                                                • 公民通过公共沟通达成政治正当性。

                                                政治哲学的核心议题 #

                                                1. 政治权力的合法性（Legitimacy） #

                                                • 为什么国家有权统治？
                                                • 统治者是否需要被统治者同意？

                                                2. 正义（Justice） #

                                                • 何为公平？
                                                • 如何衡量结果与程序的正义性？

                                                3. 自由（Liberty） #

                                                • 消极自由：不被干涉。
                                                • 积极自由：自我主宰、共同立法。

                                                4. 权利（Rights） #

                                                • 自然权利 vs 法定权利
                                                • 集体权利 vs 个体权利

                                                5. 民主（Democracy） #

                                                • 代议制 vs 直接民主
                                                • 多数暴政 vs 少数保护
                                                • 公意 vs 民意

                                                6. 主权（Sovereignty） #

                                                • 何为主权？
                                                • 主权是否应受到限制？
